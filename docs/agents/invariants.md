# Invariant ids

One numbered list of the repo's load-bearing invariants. Each carries the full
sentence exactly once; the agent docs, `AGENTS.md` and the `tests/check_*.sh`
headers cite the id (`INV-01`…) instead of restating it, so a moved sentence is
found in one place. The rows are one-line pointers: the argument lives in the
owning document named at the end of each row, and an ADR body is never restated
here (`docs/agents/domain.md`). `tests/test_agent_docs.py` fails when a cited id
is missing from this list or a row is cited nowhere. Append new rows at the end;
never renumber an existing id.

- **INV-01** — The minimum supported OS is Windows 10 (Windows 8.1 is end of life and deliberately unsupported); use APIs available since Windows 10. Owns: `docs/adr/0001-windows-support-floor.md`.
- **INV-02** — Adding one cinbase setting is one `CONFIG_RECORDS` row: the class attribute, the shipped `config/config.json` (the deterministic `write_shipped_configs()` writer — its per-`overrides` map is the per-Service shipped-config trap, nine files today), the shared settings page, and the `CinTable` mirror pair for table-affecting rows all derive from that row. Owns: `docs/agents/cinbase-config.md`, pinned by `tests/test_cinbase_config_keys.py`.
- **INV-03** — Every added file header, commit message and PR body carries one of the standing rules' AI-declaration forms. Owns: `docs/agents/code-review.md`; gates `tests/check_ai_declarations.sh`, `tests/check_pr_bodies.sh`, `tests/check_pr_commit_declarations.sh`.
- **INV-04** — The rime glog stream prints the `E1112 … Error loading config from '<tmp>\default.yaml'` and `E1113 …` lines as the expected reading of the empty traits file on every rime test run; the Python layer's `OK` line is the verdict and those lines are not failures. Owns: `docs/agents/librime-api.md`.
- **INV-05** — There is exactly one committed wire-fixture file, `tests/wire-fixtures.json`, and every backend adapter's suite iterates it instead of carrying its own request/reply set. Owns: `tests/wire-fixtures.json`, iterated by `tests/test_server_protocol.py`, `node/test/server.test.js`, `node/tests/nimeServer.test.js`, `go-backend/server_integration_test.go` and `PIMELauncher/src/protocol.rs`.
- **INV-06** — Every `tests/check_*.sh` gate and self-test prints its step status through the shared implementation in `tests/gate_lib.sh` (`gate_root`, `gate_run`, `gate_run_bounded`) except the two without a git-root prologue, `tests/check_fork_ci_noise.sh` and `tests/check_sh_exec_bits.sh`; there is no per-script copy of the prologue. Owns: `tests/gate_lib.sh`, pinned by `tests/check_gate_lib_test.sh`.
- **INV-07** — One `ime.json` per backend per IME: profile GUIDs are distinct within one file and never compared across twins, and the `locale`/`fallbackLocale` pair is the only cross-twin invariant. Owns: `docs/adr/0004-per-backend-profile-guids.md`, pinned by `tests/test_rime_registration_locale.py`.
- **INV-08** — The 筆畫 stroke table is derived from the CNS11643 全字庫 `CNS_strokes_sequence.txt` stroke-sequence data (OGDL-1.0, joined to Unicode via CNS2UNICODE) with every prefix emitted as its own key, not copied from brise. Owns: `docs/adr/0002-stroke-table-from-cns11643-with-prefix-expansion.md`, generated by `python/cinbase/tools/cnsstroke2cin.py`, pinned by `tests/test_cinbase_stroke_table.py`.
- **INV-09** — The cinbase table-load policy lives in the shared `TableHolder` in `python/cinbase/cintablebase.py` (`ensure`/`wait_until_ready`/`reset`), which all nine cinbase-family Services use; the loader trio in `python/cinbase/__init__.py` stays upstream-owned (PR #1004) and untouched. Owns: `docs/adr/0003-table-load-policy-lives-with-the-service.md`.
- **INV-10** — The reply-key list of `tests/wire-fixtures.json` — `replyKeys` plus `extraKeys` — is the one declared set of reply fields every adapter asserts against. Owns: `tests/wire-fixtures.json`, consumed as `DECLARED_KEYS` by `node/test/server.test.js`, `node/tests/nimeServer.test.js` and `tests/test_server_protocol.py`.
