## Problem

The same invariant is written down two or three times, and each gate re-types it
again in a comment: the Windows 10 support floor (`AGENTS.md`, `ADR-0001`,
`docs/agents/verification.md`), the config quartet
(`docs/agents/cinbase-config.md`, `tests/test_cinbase_config_keys.py`), the
declaration footer (`docs/agents/code-review.md`, `tests/check_tracker_layout.sh`),
the expected rime `E1112` line (`docs/agents/librime-api.md`, the rime cases).
Drift is visible only when a check disagrees with itself.

## Solution

One numbered invariant list at the top of the agent docs; the prose and the gate
headers cite the id instead of restating the sentence, and each gate prints the
id in its PASS line.

## Verification

`bash tests/check_tracker_layout.sh` and `bash tests/run_local_tests.sh` green;
`tests/test_agent_docs.py` extended to assert that every id printed by a gate
exists in the list.
