(`diff` against `cheliu_ime.py`): the interface is four data points —

implementation is a copy of the copy. A fix landed in one file does not reach
the others.

## Solution

directory's existing `ime.json`; each `*_ime.py` becomes a 3–6 line binding (or
disappears and the loader imports the shared class with the directory name).
The three empty `CinTableBase` subclasses per file fold into the ticket-05
holder.
